### **Prefabs in Unity**

A **Prefab** is a reusable GameObject that can be configured with all its components and properties. Prefabs are a core part of Unity, helping developers avoid redundant work and making it easier to create instances of the same object throughout a project.

#### **Key Prefab Concepts:**

1. **Creating Prefabs**:  
   * You can create a prefab by dragging a GameObject from the **Hierarchy** to the **Project** window, where it will be stored as an asset.  
2. **Prefab Instances**:  
   * Prefabs can be instantiated in the scene multiple times, each instance sharing the same configuration. If you modify a prefab, all instances can be updated (or overridden) with the changes.  
3. **Prefab Variants**:  
   * **Prefab Variants** are like child-prefabs that inherit from a base prefab but allow you to make specific changes to them.  
4. **Nested Prefabs**:  
   * Unity supports **nested prefabs**, where a prefab can contain other prefabs as part of its structure.
