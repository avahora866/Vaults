The basics of **values** in drawing refer to how light or dark something appears. Values are crucial because they create the illusion of form, depth, and atmosphere in art.

1. **Value Scale** – A range of tones from pure white to pure black, with grays in between.
2. **Light Source & Shadows** – Values depend on how light interacts with a subject. Understanding highlights, midtones, and shadows is essential.
3. **Contrast** – The difference between light and dark areas. High contrast makes things stand out, while low contrast creates a softer look.
4. **Planes & Form** – Objects are three-dimensional, and different planes (surfaces) catch light differently. Value changes help describe this.
5. **Atmospheric Perspective** – Distant objects appear lighter and less detailed due to atmospheric effects.

# How Values Relate to Shading Techniques

Shading is the process of using values to create the illusion of light, shadow, and depth. Here’s how different shading techniques apply values effectively:

## Understanding Light & Shadow

Before shading, it's essential to recognize the different parts of light and shadow:

- **Highlight** – The brightest part where light hits directly.
- **Midtones** – The transition between light and shadow.
- **Core Shadow** – The darkest part of the object where light is blocked.
- **Cast Shadow** – The shadow that the object casts onto a surface.
- **Reflected Light** – Light bouncing off nearby surfaces into the shadowed area.

## Shading Techniques

Here are common techniques to apply values:

- **Hatching** – Using parallel lines to create shading. Closer lines = darker values.
- **Cross-hatching** – Layers of intersecting lines to create darker tones.
- **Blending (Smooth Shading)** – Gradually transitioning between values using a pencil, brush, or smudging tool.
- **Stippling** – Using dots to create shading. More dots = darker value.
- **Scumbling** – Circular, scribbled strokes to build up texture and value.
- **Contour Shading** – Following the object's shape with curved or directional strokes to enhance form.

## Using a Value Range Effectively

- Start with **light pressure** and build up darks gradually.
- Squint your eyes to simplify and see value relationships more clearly.
- Avoid relying only on outlines—use value to define edges and form.
- Create a **value scale** (from white to black) to help match the right tones in your drawing.
