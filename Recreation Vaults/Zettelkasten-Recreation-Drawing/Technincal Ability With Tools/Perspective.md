To create a 1/2/3-point perspective:
- hold down on a layer
- ruler/frame
- create perspective ruler
- pick type of perspective (1-point, 2-point, 3-point, fisheye)
- pick whether you want the grid on a new layer (default)
- This will create the perspective ruler
To create a perspective gird, create a perspective ruler then:
- Click on the perspective with the operation
- click on the type of grid (go to tool property)
- set the scale of the grid (click the plus icon inside the operation tool property)
To snap to the grid
- Click on the perspective ruler 
- go to tool property and enable snapping
- Make sure your pen/brush/pencil has snapping enabled in their tool property
- You can toggle this snapping in the top ribbon with the snap to grid or snap to special ruler icon
