# Values
Uses a very dark value range for foreground and character. Uses a middle range of values for background

Soft blending on skin of characters

# Composition
Usually uses a darker element in the foreground (character) with a lighter values in the background to make the foreground be separate from the background. This helps create contrast.
Usually has a bit of space between any background images and the character to help emphasise the silhouette of the character
