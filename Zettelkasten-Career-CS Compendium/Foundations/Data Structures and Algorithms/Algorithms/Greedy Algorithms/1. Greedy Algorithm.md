**Greedy Algorithms** — a powerful class of algorithms used when a problem allows making **locally optimal choices** that lead to a **globally optimal solution**.

---

# What is a Greedy Algorithm?

A **greedy algorithm** builds up a solution **step-by-step**, always choosing the **best local (greedy) option** at each step without reconsidering past decisions.

It does **not** try all possibilities (like recursion or DP), but picks what seems best **right now**.

---

# Key Characteristics
* **Greedy Choice Property**: A global optimum can be arrived at by choosing a local optimum.
* **Optimal Substructure**: Optimal solution contains optimal solutions to subproblems.

# Classic Greedy Algorithm Examples

## Activity Selection Problem
[[Activity Selection or Interval Scheduling]]
**Problem:** Given `n` activities with start and end times, select the maximum number of activities that don't overlap.
## Greedy Strategy:

* Always pick the **activity with the earliest finishing time**.

## Java Code:

```java
import java.util.*;

class Activity {
    int start, end;
    Activity(int s, int e) { start = s; end = e; }
}

public class GreedyActivitySelector {

    public static int maxActivities(List<Activity> activities) {
        // Sort by end time
        activities.sort(Comparator.comparingInt(a -> a.end));

        int count = 0, lastEnd = 0;

        for (Activity act : activities) {
            if (act.start >= lastEnd) {
                count++;
                lastEnd = act.end;
            }
        }

        return count;
    }

    public static void main(String[] args) {
        List<Activity> list = List.of(
            new Activity(1, 3),
            new Activity(2, 4),
            new Activity(3, 5),
            new Activity(0, 6),
            new Activity(5, 9),
            new Activity(5, 7),
            new Activity(8, 9)
        );

        System.out.println("Max non-overlapping activities: " + maxActivities(list));
    }
}
```

## Fractional Knapsack (Greedy version)
You can take **fractions** of items (unlike 0/1 Knapsack). Maximize total value.

## Greedy Strategy:
* Sort items by **value/weight ratio**
* Take the most valuable per unit weight first

## Dijkstra’s Algorithm (Shortest Path)
[[Dijkstra’s Algorithm]]
Greedily picks the **closest unvisited node**.

---

## Minimum Spanning Tree
[[Kruskal’s and Prim’s Algorithm (MST)]]

Both use greedy logic to build a minimum-cost tree connecting all nodes.

---

# When Greedy Works
Greedy algorithms work well **only** when:
* The problem has **greedy choice property**
* The problem has **optimal substructure**
If either fails → use **Dynamic Programming** instead.

# Summary Table

| Problem | Strategy | Greedy Choice |
| ----- | ----- | ----- |
| Activity Selection | Earliest end time | Pick earliest finisher |
| Fractional Knapsack | Highest value/weight ratio | Best bang per unit |
| Dijkstra | Shortest known distance | Closest node first |
| Kruskal (MST) | Sort edges by weight | Smallest edge first |
| Prim (MST) | Closest connected vertex | Least cost edge |
