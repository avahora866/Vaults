# How to take notes
1. Pick a topic and create a folder for it
2. Create a master note inside the folder and start making notes from as you start to learn it. 
3. Any sub topics should have a small explanation in the master note as well as the link to a more in depth explanation stored in the same folder
4. For bigger topic we can have multiple master notes
	- In the case of java i will have one major note called "Java" that is a general note i can read before interviews to get a goood understanding of the major concepts in java
	- In the java folder will have multiple other notes like "Architecture", "Concurrency", "Data structure" that will go deeper into the topics
This format is so that when I go back to review a topic I have a proper flow I can read through instead of multiple notes I have to keep switching between
