Spring Framework consists of all the Spring projects  
The Spring Framework is divided into modules.   
The core container is a collection of modules that are paramount to the Spring Framework

Spring Framework's jar allow for deployment in module path (Java Module System) as well as class path

Spring was released in 2003 as a response to the early J2EE specification

It does not implement the Jakarta EE specification fully but instead integrates with selected individual specifications from the traditional EE umbrella

* Servlet API (JSR 340\)  
* WebSocket API (JSR 356\)  
* Concurrency Utilities (JSR 236\)  
* JSON Binding API (JSR 367\)  
* Bean Validation (JSR 303\)  
* JPA (JSR 338\)  
* JMS (JSR 914\)  
* JTA/JCA setups for transaction coordination, if necessary  
* Dependency Injection (JSR 330\)  
* Common Annotations (JSR 250\)
