TypeScript is a **strongly typed, object-oriented, compiled programming language** that builds on JavaScript. It was developed by Microsoft to enhance JavaScript by adding **static typing** and other advanced features, making it more robust for large-scale applications.

# Key Features of TypeScript:

1. **Static Typing** – Unlike JavaScript, TypeScript allows developers to define variable types (e.g., `string`, `number`, `boolean`), reducing runtime errors.

2. **Compiles to JavaScript** – TypeScript code is transpiled into plain JavaScript, ensuring compatibility with browsers and JavaScript environments.

3. **Object-Oriented Features** – Supports interfaces, classes, inheritance, and access modifiers, making it easier to build structured applications.

4. **Enhanced Tooling & Autocompletion** – Offers better IntelliSense support in editors like VS Code, improving code suggestions and error detection.

5. **Optional Typing** – Developers can choose whether to use static types, making TypeScript flexible.

6. **Modern JavaScript Support** – TypeScript includes ES6+ features (e.g., async/await, modules) and compiles them to compatible JavaScript.

# Why Use TypeScript?

* Helps catch errors during development instead of runtime.

* Improves code maintainability and scalability.

* Provides better collaboration in teams by enforcing clear types and interfaces.

# Example of TypeScript Code:

```
function greet(name: string): string {
    return `Hello, ${name}!`;
}

console.log(greet("Alice"));
```

In this example, `name` is explicitly typed as a `string`, ensuring that only string values can be passed.
