Memory is an electronic holding place for the instructions and data a computer needs to reach quickly. It’s where information is stored immediate use.

2 types of memory:

- primary memory: one specific type of primary memory is Random Access Memory (RAM)
- secondary memory: slower than primary

# Memory v Storage

**Memory** is primary (RAM) and **storage** is secondary (Hard drive or a Hard Disk). **Storage** is _non-volatile_ meaning the information is still there after the computer is turned of and then back on. Whilst **memory** is the opposite, _volatile_ meaning it isn't retained when the computer is turned off.
