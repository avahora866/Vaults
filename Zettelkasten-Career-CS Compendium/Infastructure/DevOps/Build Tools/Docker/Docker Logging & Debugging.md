# Viewing Container Logs

The `docker logs` command allows you to view the logs generated by a running or stopped container. It is particularly useful for debugging and monitoring the output from processes running inside the container.

## Syntax:

```shell
docker logs container-name
```

*   
  **`container-name`**: The name or ID of the container whose logs you want to view.

## Example:

```shell
docker logs myapp_container
```

This will display the logs from the container named `myapp_container`.

## Common Flags:

* **`-f` or `--follow`**: Continuously stream the logs (like `tail -f`).

   Example:

```shell
docker logs -f myapp_container
```

*   
  **`--tail`**: Shows the last N lines of the logs. For example, `--tail 100` shows the last 100 lines of logs.

   Example:

```shell
docker logs --tail 100 myapp_container
```

*   
  **`--since`**: Show logs since a specific time (e.g., `--since 10m` shows logs from the last 10 minutes).

# Inspecting Container Details

The `docker inspect` command provides detailed information about a container, such as its configuration, runtime parameters, networking, environment variables, and more.

## Syntax:

```shell
docker inspect container-name
```

*   
  **`container-name`**: The name or ID of the container you want to inspect.

## Example:

```shell
docker inspect myapp_container
```

This will display detailed information about the container named `myapp_container` in JSON format. This includes things like:

* Container ID

* Network settings

* Mounted volumes

* Environment variables

* Configuration options (e.g., command used to run the container)

You can also use a **filter** to get specific details. For example, if you just want to see the container's IP address:

```shell
docker inspect --format '{{ .NetworkSettings.IPAddress }}' myapp_container
```

# Checking Resource Usage

The `docker stats` command displays real-time statistics about running containers, including CPU, memory, network, and disk I/O usage. This is useful for monitoring the resource consumption of containers.

## Syntax:

```shell
docker stats
```

This shows statistics for **all running containers** by default.

## Example:

```shell
docker stats myapp_container
```

This will show resource usage for a specific container named `myapp_container`.

## Output Includes:

* **CPU Usage**: The percentage of CPU being used by the container.

* **Memory Usage**: The amount of memory being used, along with the total available memory.

* **Network I/O**: The amount of data the container has sent and received.

* **Disk I/O**: The amount of data the container has read and written to disk.

## Common Flags:

* **`--no-stream`**: Displays the stats once and then exits, without continuous updates.

   Example:

```shell
docker stats --no-stream
```

# Entering a Running Container

The `docker exec` command allows you to execute commands inside a running container. This is useful for debugging, running administrative tasks, or interacting with the container's environment.

## Syntax:

```shell
docker exec -it container-name command
```

*   
  **`container-name`**: The name or ID of the running container.

* **`command`**: The command you want to execute inside the container (e.g., `bash` to start an interactive shell).

## Example:

To enter a running container and start a Bash shell:

```shell
docker exec -it myapp_container bash
```

This will give you an interactive terminal (`-it` flag) inside the container. Once inside, you can run commands as if you were inside the container’s environment.

## Common Use Cases:

* **Inspecting the container's filesystem**: You can browse and modify files inside the container.

* **Running diagnostics**: Running tools like `top`, `ps`, `df`, etc., to diagnose issues.

* **Interacting with the app**: If the container is running an app, you can interact with it or troubleshoot directly inside the container.

# Summary

* **Viewing container logs (`docker logs container-name`)**: Shows the logs from a specific container, which can help with debugging and monitoring.

* **Inspecting container details (`docker inspect container-name`)**: Provides detailed information about the container's configuration, networking, environment, and more.

* **Checking resource usage (`docker stats`)**: Displays real-time statistics about resource consumption (CPU, memory, network, disk) of running containers.

* **Entering a running container (`docker exec -it container-name bash`)**: Allows you to run commands inside a running container, useful for troubleshooting or interacting with the container’s environment.

These commands are essential for managing and maintaining Docker containers, providing insight into their performance and configuration while allowing you to interact with them directly.
