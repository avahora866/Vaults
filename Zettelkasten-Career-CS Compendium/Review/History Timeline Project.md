# Overview

React project to help view my history notes in an interactive way.

When the application first loads, the user will be presented with a map as well as a timeline viewer. Using the map the user will be able to view the timeline of the world with the map changing to show the fall and rise of different kingdoms.

The user will be prompted for access to a folder in their system by clicking a button in the top left hand corner. The folder should include markdown files that contain a string that the application will search for.  
The string being a marker of where and when to place the pin (longititue:latitutde:time).

Once the application has access to the folder it will traverse the folder and subfolders to find markdown files with the string and will place a pin on the map accordingly.

Clicking on a pin will allow the user to preview the note and clicking full screen will show the full note on the right hand side.

*Note: In google gemini there is a canvas conversation of this timeline viewer that i can use as a base*
