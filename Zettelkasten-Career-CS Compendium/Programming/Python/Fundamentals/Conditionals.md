Used to execute code based on conditions.

# Basic `if` Statement

```py
age = 18
if age >= 18:
    print("You are an adult.")
```

**Output:**

```
You are an adult.
```

# `if-else` Statement

```py
num = 10
if num % 2 == 0:
    print("Even number")
else:
    print("Odd number")
```

**Output:**

```
Even number
```

# `if-elif-else` Chain

```py
score = 75

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")
else:
    print("Grade: F")
```

**Output:**

```
Grade: C
```
