# For Loop

Used to iterate over a sequence (list, tuple, string, etc.).

```python
numbers = [1, 2, 3, 4, 5]
for num in numbers:
    print(num)
```

**Output:**

```
1
2
3
4
5
```

# While Loop

Repeats as long as a condition is `True`.

```python
count = 0
while count < 3:
    print("Hello")
    count += 1
```

**Output:**

```
Hello
Hello
Hello
```

# Iterating Over a String

```python
for char in "Python":
    print(char)
```

**Output:**

```
P
y
t
h
o
n
```
