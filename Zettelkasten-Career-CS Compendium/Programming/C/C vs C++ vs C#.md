# C

Developed in the early 1970s.  
Low-level, procedural language.  
Efficient and close to hardware, widely used in system programming (OS, embedded systems).

# C++

* Created in the 1980s as an extension of C.  
* Supports both procedural and [[_Object Oriented Programming (OOP)|object-oriented programming (OOP).]]  
* Used for high-performance applications, game development, and large-scale software systems.

# C\#

* Developed by Microsoft in the early 2000s.  
* High-level, managed language running on the .NET framework.  
* Includes garbage collection, modern OOP features, and is used for Windows applications, enterprise software, and Unity game development.

# Relationship

* C++ extends C by adding OOP and additional features while maintaining C's efficiency.  
 C\# is influenced by both C and C++ but is designed for a higher level of abstraction and modern development, especially within the .NET ecosystem.  
* They share similar syntax but serve different purposes and have distinct runtime environments.
