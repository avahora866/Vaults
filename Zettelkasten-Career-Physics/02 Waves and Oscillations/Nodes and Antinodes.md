# Nodes and Antinodes

In a standing wave, a **node** is a point that never moves — the two component waves are always exactly out of phase there, so they cancel completely at every instant. An **antinode** is a point of maximum oscillation, where the two component waves are always exactly in phase, reinforcing each other fully.

Nodes and antinodes alternate along the wave, spaced $\lambda/4$ apart (a node, then an antinode a quarter-wavelength away, then another node a further quarter-wavelength away, and so on). The distance between two adjacent nodes (or two adjacent antinodes) is half a wavelength, $\lambda/2$.

**Boundary conditions determine the pattern.** A string fixed at both ends must have a node at each end (since the string can't move there); this forces only certain wavelengths to fit — exactly those where a whole number of half-wavelengths spans the string's length $L$:

$$
L = n\frac{\lambda_n}{2}, \qquad n = 1, 2, 3, \dots
$$

Each allowed $n$ corresponds to a **harmonic** — the fundamental ($n=1$) plus a discrete ladder of overtones. This is directly why a plucked guitar string sounds like a specific musical note rather than an arbitrary noise: only specific wavelengths (and hence frequencies) are geometrically allowed to form a standing wave on that string.
