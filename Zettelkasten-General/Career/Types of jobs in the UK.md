# Common Job Types in the UK

## By Employment Type

| Type               | Description                                                                        |
| ------------------ | ---------------------------------------------------------------------------------- |
| **Permanent**      | Ongoing employment with benefits (e.g. holiday, sick pay, pension)                 |
| **Fixed-term**     | Contracted for a set period (e.g. maternity cover, 6-month project)                |
| **Temporary**      | Short-term work, often via agencies                                                |
| **Contract**       | Hired for a specific task or time, often via a limited company or umbrella company |
| **Freelancer**     | Self-employed, usually juggling multiple clients or projects                       |
| **Zero-hours**     | No guaranteed hours; work only when needed                                         |
| **Internship**     | Short-term role, often for students or recent graduates (can be paid/unpaid)       |
| **Apprenticeship** | Paid work + study, leads to qualifications                                         |

## By Working Arrangement

| Type           | Description                                |
| -------------- | ------------------------------------------ |
| **Full-time**  | Typically 35–40 hours/week                 |
| **Part-time**  | Fewer hours than full-time                 |
| **Remote**     | Work done from home or anywhere else       |
| **Hybrid**     | Mix of remote and in-office work           |
| **Shift work** | Set hours outside 9–5 (e.g., night shifts) |

# IR35 and Contract Jobs

**IR35** is a UK tax rule that applies to **contract roles** where you work through an intermediary (usually a limited company or "personal service company").

Its purpose is to prevent **"disguised employment"**—people avoiding tax by working like an employee but invoicing through a company.

## Inside vs Outside IR35: Key Differences

| Feature                     | Inside IR35                                                 | Outside IR35                                 |
| --------------------------- | ----------------------------------------------------------- | -------------------------------------------- |
| **Employment Status (Tax)** | Treated like an employee for tax purposes                   | Treated as self-employed                     |
| **Tax Handling**            | Income Tax and NI deducted at source (PAYE)                 | Responsible for own taxes; can use dividends |
| **Payment**                 | Paid like an employee, often via umbrella company           | Paid gross to your limited company           |
| **Business Expenses**       | Can't claim most expenses                                   | Can claim allowable business expenses        |
| **IR35 Decision Maker**     | Client (in public sector or medium/large private companies) | You (if client is a small private company)   |
| **Substitution Allowed?**   | Often not allowed                                           | Typically allowed                            |
| **Control Over Work**       | Client directs how/when work is done                        | You decide how to deliver the work           |
| **Mutual Obligation**       | Ongoing work expected by both sides                         | Work is project-based and limited in scope   |
| **Rights (Sick, Holiday)**  | No statutory rights unless through umbrella                 | No statutory rights                          |

## Summary

* **Inside IR35**: Treated like a de facto employee. Higher tax, lower take-home pay. Simpler but less flexible.
* **Outside IR35**: True contract. More tax-efficient, but more risk and responsibility.
