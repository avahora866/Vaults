A quantitative developer (quant dev) builds and maintains the software used by quantitative analysts at financial institutions like banks, hedge funds, and trading firms.

# Core Responsibilities

- Develop trading systems (real-time pricing, execution, risk management)
- Implement mathematical models in code
- Optimize performance and reliability
- Collaborate with traders, quants, and engineers

# Key Skills

| Area             | Examples                                |
| ---------------- | --------------------------------------- |
| Programming      | Java, C++, Python, Rust                 |
| Computer Science | Algorithms, concurrency, systems design |
| Finance          | Options, derivatives, risk management   |
| Math             | Linear algebra, probability, calculus   |
| Tools            | Git, Linux, CI/CD, SQL, KDB+            |

# Types of Quant Dev Roles

| Role Type             | Description                             | Tech Focus                   |
| --------------------- | --------------------------------------- | ---------------------------- |
| Core Infrastructure   | Internal platforms and dev tooling      | General software engineering |
| Model Implementation  | Translating math models into production | Numerical methods, math      |
| Execution/Trading Sys | Low-latency systems for live trading    | C++, networking              |
| Data Engineering      | Handling time series and market data    | Python, data pipelines       |

# Buy Side vs Sell Side

| Type      | Description                                | Examples                      | Focus                                  |
| --------- | ------------------------------------------ | ----------------------------- | -------------------------------------- |
| Buy Side  | Works for investment managers, hedge funds | Citadel, Two Sigma, BlackRock | Strategy development, alpha generation |
| Sell Side | Works for banks and brokerages             | JPMorgan, Goldman Sachs       | Pricing models, risk, client tools     |

# Front Office vs Middle/Back Office

| Area          | Description                       | Notes                         |
| ------------- | --------------------------------- | ----------------------------- |
| Front Office  | Trading, strategy, pricing        | High pressure, low latency    |
| Middle Office | Risk, compliance, PnL attribution | More stable, less urgent      |
| Back Office   | Settlements, reporting            | Operational, batch processing |

# Work-Life Balance

- Varies widely by firm, team, and role
- Generally 9-10 hour days, some weekend or on-call work
- HFT and trading systems roles tend to be more demanding
- Less intense than front-office quant roles but more than typical big tech jobs
